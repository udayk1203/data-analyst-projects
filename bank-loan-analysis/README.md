# Bank Loan Analysis

## Project Overview

This project analyzes bank loan data to understand loan performance, borrower characteristics, repayment patterns, and key financial indicators.

The analysis was performed using **Microsoft Excel, SQL, Power BI, and Tableau**.

## Objectives

* Analyze loan applications and funded loan amounts
* Track loan performance and loan status
* Analyze loan grades and sub-grades
* Compare verified and non-verified loan payments
* Analyze loan trends by year, state, and month
* Examine relationships between home ownership and loan performance
* Develop interactive dashboards and KPI reports

## Tools & Technologies

* **Microsoft Excel** — Data cleaning, PivotTables, Power Query, Power Pivot, charts, and dashboard reporting
* **SQL** — Data querying, aggregation, filtering, joins, and analysis
* **Power BI** — Data modeling, DAX, KPI reporting, interactive dashboards, and visual analysis
* **Tableau** — Interactive dashboards, filters, calculated fields, and trend analysis

## Key Analysis Areas

### Loan Performance

Analysis of loan amounts, loan status, funded amounts, and payment-related metrics.

### Risk Analysis

Analysis by loan grade, sub-grade, verification status, and other borrower-related attributes.

### Geographic Analysis

Analysis of loan activity and loan status across different states and ZIP-code groups.

### Customer & Loan Characteristics

Analysis based on home ownership, employment-related attributes, and other available loan characteristics.

## Key KPIs

* Total Loan Amount
* Funded Amount
* Loan Applications
* Average Interest Rate
* Loan Status
* Payment-to-Funded Ratio
* Loan Performance by Grade and Sub-Grade
