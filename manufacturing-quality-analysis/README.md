# Manufacturing Quality Analysis

## Project Overview

This project analyzes manufacturing production and quality data to understand production output, rejected units, processed units, wastage, and quality performance.

The analysis focuses on identifying rejection patterns across employees, machines, and departments and presenting key manufacturing KPIs through data analysis and visualization.

## Objectives

* Analyze total manufactured and processed units
* Measure rejected units and wastage
* Analyze rejection patterns by employee
* Analyze rejection patterns by machine
* Compare quality performance across departments
* Identify manufacturing and quality trends
* Develop KPI-based analytical reports and dashboards

## Tools & Technologies

* **Microsoft Excel** — Data analysis, KPI calculations, and reporting
* **SQL** — Data querying, aggregation, filtering, and analysis
* **Power BI** — Data visualization, KPI reporting, and dashboard development

## Key Analysis Areas

### Production Analysis

Analysis of manufactured and processed units to understand overall production performance.

### Quality Analysis

Analysis of rejected units and wastage to identify quality-related patterns.

### Employee Analysis

Comparison of rejection performance across employees to identify differences in quality outcomes.

### Machine Analysis

Analysis of rejection rates and quality performance across different machines.

### Department Analysis

Comparison of production and rejection performance across departments.

## Key Metrics

* Total Manufactured Units
* Total Processed Units
* Total Rejected Units
* Total Wastage
* Employee Rejection
* Machine Rejection
* Department-wise Performance
