# Power BI Dashboard

Interactive Power BI dashboard developed for the Manufacturing Quality Analysis project.

The dashboard focuses on manufacturing output, rejected quantity, processed quantity, wastage percentage, and quality performance across employees, machines, departments, and brands.

## Key Analysis

* Manufacturing quantity
* Processed quantity
* Rejected quantity
* Wastage percentage
* Employee-wise rejection
* Machine-wise rejection
* Department-wise performance
* Brand-wise performance
* Monthly manufacturing and rejection trends

The original source dataset and Power BI `.pbix` file are not included in this repository.

Dashboard screenshots are available in the `screenshots` folder.
