# Data Analyst Projects

Data Analyst portfolio projects focused on **Microsoft Excel, SQL, Power BI, Tableau, Data Cleaning, Data Visualization, and KPI Reporting**.

## About This Portfolio

This repository contains practical data analysis projects demonstrating the end-to-end process of transforming data into meaningful insights and business-focused dashboards.

The projects cover areas including **finance, hospitality, and manufacturing quality analysis**.

**Tools:** Excel | SQL | Power BI | Tableau

Analysis of bank loan data covering loan performance, risk analysis, loan grades, verification status, geographic trends, and key financial KPIs.

**Key areas:**

* Loan performance analysis
* Risk analysis
* Grade and sub-grade analysis
* Loan status analysis
* Geographic analysis
* KPI reporting
* Interactive dashboards

### 2. Hospitality Analysis

**Tools:** Excel | Power BI | Power Query | Power Pivot

Analysis of hospitality booking data covering bookings, revenue, occupancy, cancellations, and operational KPIs.

**Key KPIs:**

* Total Bookings: **134,590**
* Revenue: **1,708,771,229**
* Cancelled Bookings: **33,420**
* Cancellation Rate: **24.83%**
* Occupancy Rate: **57.87%**

[View Hospitality Analysis](./hospitality-analysis/)

### 3. Manufacturing Quality Analysis

**Tools:** Excel | SQL | Power BI | Tableau

Analysis of manufacturing production and quality data covering manufactured quantity, processed quantity, rejected quantity, wastage, and quality performance.

**Key areas:**

* Production analysis
* Rejection analysis
* Employee-wise analysis
* Machine-wise analysis
* Department-wise analysis
* Brand-wise analysis
* Monthly production trends
* KPI reporting

[View Manufacturing Quality Analysis](./manufacturing-quality-analysis/)
