# Hospitality Analysis

## Project Overview

This project analyzes hospitality booking data to understand booking performance, revenue, occupancy, cancellations, and key operational KPIs.

The analysis was performed using **Microsoft Excel and Power BI**, with **Power Query and Power Pivot** used for data preparation, modeling, and analysis.

## Objectives

* Analyze overall booking performance
* Monitor revenue and booking trends
* Analyze occupancy performance
* Measure booking cancellations
* Calculate key hospitality KPIs
* Create interactive dashboards and visual reports
* Identify trends and patterns in hospitality operations

## Tools & Technologies

* **Microsoft Excel** — Data cleaning, Power Query, Power Pivot, PivotTables, KPI calculations, charts, and dashboard reporting
* **Power BI** — Data visualization, KPI reporting, interactive dashboards, and analytical reporting

## Key Analysis Areas

### Booking Analysis

Analysis of total bookings and booking trends to understand overall business performance.

### Revenue Analysis

Analysis of revenue generated from hospitality bookings and related performance indicators.

### Occupancy Analysis

Analysis of occupancy rate to understand room utilization and operational performance.

### Cancellation Analysis

Analysis of cancelled bookings and cancellation rate to identify booking loss patterns.
